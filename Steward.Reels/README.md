# Steward.Reels

Бот в Telegram, который превращает рилсы в идеи. Присылаешь ссылку на рилс Instagram, через пару минут идея появляется в приложении на странице «Идеи» с кнопками «Делаем» и «Отклонить».

## Как работает

Задача `reels` в `config/jobs.json` запускает программу при старте приложения и каждые 5 минут. Один запуск:

1. Читает новые сообщения бота (`getUpdates`, номер прочитанного лежит в `data/reels/offset.txt`).
2. Отвечает только владельцу (`AllowedUserId`), остальных пропускает молча.
3. Для каждой ссылки: если рилс уже разбирали (ссылка есть в `data/reels/seen.txt` или среди идей), бот спрашивает кнопками «Добавить ещё раз» и «Не надо» и ничего не делает до ответа. Новую ссылку `yt-dlp` скачивает, Whisper расшифровывает речь, а Claude Code (`claude -p` без инструментов) придумывает название идеи и пишет краткий разбор: суть, для чего, плюсы, минусы, вывод. Идея ложится в `data/ideas/<id>.json`. Видео и звук сразу удаляются. Если Claude не ответил, название берётся из подписи, а разбора нет.
4. Из названия и разбора убираются смайлики и скрытые символы.
5. Отвечает в Telegram: «Принял», потом «Готово: название» или «Не получилось: причина».
6. Пишет в статус число идей без решения. Приложение показывает его на плашке задачи как «Без решения: N».

Если Instagram потребует вход, бот ответит причиной, а журнал покажет ошибку с кнопкой починки.

## Что делает кнопка «Делаем»

Идея остаётся в списке с пометкой «в работе», пока ты сам не нажмёшь «Удалить»: ссылка при этом остаётся в `seen.txt`, и бот спросит, если её пришлют снова. Кнопка открывает Claude Code в папке репозитория с готовой просьбой: пересказать идею, определить тип идеи (улучшение работы с Claude, фича для проектов, знание, бесполезное) и действовать по типу: шаги установки плагина или настройки, план фичи, короткая заметка. Просьбу отправляешь ты сам, ничего не запускается без тебя. В просьбе только путь к файлу идеи: текст из интернета Claude считает данными, а не инструкциями.

## Настройка

1. В Telegram напиши `@BotFather`, команда `/newbot`, получи токен.
2. Собери программу:
   ```powershell
   dotnet publish Steward.Reels -c Release -o Steward.Reels/publish
   ```
3. Скопируй `Steward.Reels/appsettings.example.json` в `Steward.Reels/publish/appsettings.json` и впиши `BotToken`. Файл в `.gitignore`. Программа читает только файл в `publish`, копия в папке проекта игнорируется.
   Если Instagram отвечает «empty media response» или просит вход, впиши в `CookiesFromBrowser` браузер, где ты вошёл в Instagram: `firefox`, `chrome` или `edge`. Программа только читает cookies, пароль ей не нужен. Надёжнее всего Firefox: Chrome и Edge на Windows иногда не отдают cookies, пока браузер открыт.
4. Убедись, что в `Whisper` есть `.venv` с `yt-dlp` (`Whisper/setup.ps1` ставит всё сразу).
5. Включи задачу: в `config/jobs.json` у `reels` поставь `"enabled": true`.
6. Напиши боту любое сообщение. Пока `AllowedUserId` равен 0, он ответит твоим Telegram id. Впиши его в `appsettings.json`, ещё раз проверь запуск кнопкой «Запустить».
