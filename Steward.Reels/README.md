# Steward.Reels

Бот в Telegram, который превращает рилсы в идеи. Присылаешь ссылку на рилс Instagram, через пару минут идея появляется в приложении на странице «Идеи» с кнопками «Делаем» и «Отклонить».

## Как работает

Задача `reels` в `config/jobs.json` запускает программу при старте приложения и каждые 5 минут. Один запуск:

1. Читает новые сообщения бота (`getUpdates`, номер прочитанного лежит в `data/reels/offset.txt`).
2. Отвечает только владельцу (`AllowedUserId`), остальных пропускает молча.
3. Для каждой ссылки: `yt-dlp` скачивает звук без входа в аккаунт, Whisper расшифровывает речь, в `data/ideas/<id>.json` пишется идея (название, автор, подпись, расшифровка, ссылка). Видео и звук сразу удаляются.
4. Отвечает в Telegram: «Принял», потом «Готово: название» или «Не получилось: причина».
5. Пишет в статус число идей, которые ждут решения. Приложение показывает его на плашке задачи.

Если Instagram потребует вход, бот ответит причиной, а журнал покажет ошибку с кнопкой починки.

## Что делает кнопка «Делаем»

Открывает Claude Code в папке репозитория с готовой просьбой: пересказать идею, оценить пользу для проектов, предложить план. Просьбу отправляешь ты сам, ничего не запускается без тебя. В просьбе только путь к файлу идеи: текст из интернета Claude считает данными, а не инструкциями.

## Настройка

1. В Telegram напиши `@BotFather`, команда `/newbot`, получи токен.
2. Собери программу:
   ```powershell
   dotnet publish Steward.Reels -c Release -o Steward.Reels/publish
   ```
3. Скопируй `Steward.Reels/appsettings.example.json` в `Steward.Reels/publish/appsettings.json` и впиши `BotToken`. Файл в `.gitignore`.
4. Убедись, что в `Whisper` есть `.venv` с `yt-dlp` (`Whisper/setup.ps1` ставит всё сразу).
5. Включи задачу: в `config/jobs.json` у `reels` поставь `"enabled": true`.
6. Напиши боту любое сообщение. Пока `AllowedUserId` равен 0, он ответит твоим Telegram id. Впиши его в `appsettings.json`, ещё раз проверь запуск кнопкой «Запустить».
