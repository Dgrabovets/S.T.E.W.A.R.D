# Whisper

Локальная расшифровка звука из видео и аудио. Нужна для сохранённых рилсов: речь из ролика превращается в текст, который потом разбирает агент. Расшифровки занятий MTS Link берутся готовыми со страницы, их Whisper не трогает.

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
```

Скрипт создаёт `.venv`, ставит `faster-whisper` и библиотеки CUDA (около 1,5 ГБ) и скачивает модель `large-v3` в `models/` (около 3 ГБ). Обе папки в `.gitignore`.

## Запуск

```powershell
.venv\Scripts\python.exe transcribe.py путь\к\файлу.mp4
```

Рядом с файлом появятся `.transcript.json` (с временными метками) и `.transcript.txt`. По умолчанию язык русский, `--language` меняет его. Скрипт сначала пробует видеокарту, при сбое CUDA считает на процессоре. Декодирование видео делает сама библиотека, отдельный ffmpeg не нужен.
