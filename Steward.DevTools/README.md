# Steward.DevTools

Инструменты для разработки и проверки интерфейса. В приложение они не входят: приложение собирается без этого проекта, а проект подключает сборку приложения и берёт из неё окна и оформление.

## Нарисовать окно в PNG

Окна рисуются на выдуманных данных, поэтому настоящие токены и письма не нужны, а рабочая иконка в трее не мешает.

```
dotnet run --project Steward.DevTools -- snapshot файл.png [режим]
```

| Режим | Что рисует |
|-------|------------|
| `main[:status\|ideas\|homework\|journal]` | Главное окно на нужной странице |
| `main:journal:open` | Журнал с раскрытыми разделами, окно вытянуто по высоте |
| `main:done` | Карточка задачи, которая только что закончилась (проигрывается завершение) |
| `settings`, `settings:formats` | Окно настроек, во втором случае блок «Форматы заданий» раскрыт |
| `tray` | Меню трея из капель |
| `design` | Страница-образец дизайн-системы целиком: цвета, шкала текста, кнопки, поля, сферы |
| `orbs`, `icons`, `slider` | Листы вариантов: сферы, иконка трея, ползунок |
| `appicon`, `logo`, `social` | Значок приложения 512 пикселей, логотип и картинка для GitHub |

Файл значка `Steward/Assets/steward.ico` собирает `AppIconWriter` (код лежит здесь же).

## Проверить быстрый статус

```
dotnet run --project Steward.DevTools -- check-toggle
```

Открывает меню у иконки три раза подряд как щелчками по иконке и пишет, видно ли окно: должно быть «открыто, закрыто, открыто».

## Проверить живое окно

`Scripts/UiProbe.ps1` управляет открытым окном через автоматизацию интерфейса и оконные сообщения, мышь пользователя не трогает:

```powershell
. .\Steward.DevTools\Scripts\UiProbe.ps1
Save-StewardShot                      # снимок окна в data\tmp\live.png
Get-StewardToggles | % { $_.Toggle() } # раскрыть или свернуть разделы
Set-StewardScroll 100                 # прокрутить страницу вниз
Measure-StewardAnimation 1490 55 70 45 # 0, если сфера в этой области стоит
Measure-StewardCpu 10                 # загрузка процессора, % одного ядра
Test-StewardHit 1885 700              # 11 у правого края: окно растягивается
```

Запускать приложение для проверки удобно так: `Steward.exe --open Journal`.

## Проверить комментарии

`Scripts/DocScan.cs` ищет объявления без XML-комментария:

```
dotnet run --no-cache Steward.DevTools/Scripts/DocScan.cs -- <корень репозитория> [--params]
```

Должно получиться «без комментария: 0».

## Что учесть

- Окна проверяются при 96 точках на дюйм, а у человека может быть другой масштаб: перенос текста и высота строк на экране иногда отличаются.
- Живая сфера на снимке «замирает» в одном кадре, анимации проверяют скриптом `Measure-StewardAnimation`.
- Файлы `.ps1` с русскими строками должны быть в UTF-8 с BOM, иначе Windows PowerShell 5.1 читает их неправильно.
