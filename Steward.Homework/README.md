# Steward.Homework

Домашние задания по занятиям MTS Link: что нашли в расшифровке, в каком формате готовить и какие задачи завести в SingularityApp.

## Папка `data/homework`

| Путь | Кто пишет | Что внутри |
|---|---|---|
| `lessons.json` | выгрузка из MTS Link (позже) | `[{"id": "db-1022", "title": "…", "date": "2026-10-22"}]` |
| `transcripts/<id>.txt` | выгрузка из MTS Link (позже) | расшифровка занятия |
| `items/<id>.json` | агент (Claude) по просьбе из `HomeworkExtractionPrompt` | `[{"title", "due", "requirements", "link"}]` и необязательные `evidence`, `confidence`, `doubt` (см. «Конвейер»). Старые файлы без них читаются как есть |
| `analysis/<id>.json` | агент (Claude) по просьбе из `LessonAnalysisPrompt` | подробный разбор занятия: тема, что было, пройденное, темы, формулировки, решения, задачи. Полный текст по ролям сюда не попадает |
| `drafts/<id>/Задание N. …` | `DraftBuilder` | готовые работы: `.docx`, `.pptx`, `.md` или файл с кодом. Агент пишет Markdown, `OfficeWriter` собирает из него Word и презентацию |
| `guides/guides.json`, `guides/Общие/…` | вкладка «Домашние задания» | методические указания и образцы работ, общие для всех предметов: файлы копируются сюда, пути к файлам и папкам и ссылки запоминаются, ссылки Google Диска и Документов скачиваются; Word и презентации читаются через текстовую копию в `guides/.text` вместе с оформлением (шрифт, размер, интервал, поля) |
| `guides/guides.json` (новые поля) | приложение | у записи необязательные `Manual` (образец указал владелец) и `Added` (дата добавления); старый файл читается как есть |
| `samples/<предмет>/` | `GuideStore.AddSample` | копии сданных работ, образцы предмета; имя папки и файла проходит через `RemarkStore.SafeName` (недопустимые знаки убираются, при изменении имени добавляется короткий хеш) |
| `remarks/<предмет>.json`, `remarks/_all.json` | окно «Переделать», вкладка «Замечания» | замечания владельца: предметные и общие для всех предметов |
| `item-confirmed.json` | кнопка «Подтвердить» | ключи `занятие:номер` подтверждённых заданий; `item-states.json` не меняется |
| `item-overrides.json` | «Поправить условие» | правки названия и требований по ключу `занятие:номер`; правка заодно подтверждает задание |
| `prepare-attempts.json` | `HomeworkPreparer` | число неудач подряд по заданию (после 3 задание ждёт владельца) |
| `sample-registered.json` | `HomeworkPreparer` | задания, чья сданная работа уже стала образцом: удалённый владельцем образец не возвращается |
| `prepare.lock` | `HomeworkPreparer` | блокировка на время подготовки; пока она занята, вторая подготовка, прикрепление, удаление работы и «Проверить заново» отказывают |
| `drafts/<id>/.failed/` | `HomeworkPreparer` | файлы неудачной или прерванной попытки агента: не считаются готовой работой и не удаляются, имена не затираются |
| `drafts/<id>/.owner/attached.json` | `HomeworkStore.AttachOwnWork` | имена файлов работ, которые прикрепил владелец; переделка их не переносит в `.previous` |
| `created.json` | выгрузка | ключи задач и заметок, уже записанных в SingularityApp (`hw:`, `note:`, `draft:`) |
| `formats.json` | вкладка «Домашние задания» в приложении | формат по ключу занятия, по умолчанию Word |

## Поток

1. Выгрузка кладёт занятие и расшифровку (пока вручную).
2. Кнопка «Подготовить задания» в окне «Форматы ДЗ» запускает Claude в фоне одним заходом (`ClaudeAgent`: модель sonnet, только чтение и запись файлов, без сохранения сессии, чат не создаётся). Он читает расшифровку и пишет `items/<id>.json`, в окне идёт вращающаяся сфера, потом галочка или ошибка. Просьбу собирает `HomeworkExtractionPrompt`: текст расшифровки в неё не попадает, только путь, и помечен как данные, а не инструкции.
3. Программа [`Steward.Homework.Tasks`](../Steward.Homework.Tasks) создаёт задачи с ключом `hw:<занятие>:<номер>`: повторный запуск дублей не делает. Занятия с форматом «Не готовить» пропускаются.

4. После заданий `DraftBuilder` просит Claude выполнить каждое в выбранном формате и кладёт файлы в `drafts/<id>`; готовые не переделываются. `Steward.Lms` позже записывает разбор занятия в заметку SingularityApp (она обновляет заметку с резюме) и ссылку на готовый файл в задачу `hw:`. API SingularityApp (v2) не принимает вложения, поэтому в задаче лежит ссылка `file:///…` на файл на диске.

Какие материалы попадут в просьбу, решают галочки в окне «Методические указания» (`Enabled`) и отметки в окне «Подготовить задание»; дополнительное указание из того же окна добавляется в конец просьбы. Просьба на подготовку задания перечисляет методические указания (их требования обязательны) и образцы автора (ориентир по стилю и структуре, содержание не копируется), а папки с материалами по ссылкам на диск передаются агенту как `--add-dir`. Агент получает только `Read,Write`. Правилами `--disallowedTools Edit(…)` ему закрыта правка (читать всё это можно), набор правил зависит от запуска (`AgentAccessEnum`):

- всегда: дополнительные папки материалов, файлы состояния `lesson-states.json`, `item-states.json`, `item-confirmed.json`, `item-overrides.json`, `created.json`, `prepare-attempts.json`, `sample-registered.json`, `formats.json`, `subject-formats.json`, `subject-states.json`, `subject-options.json`, `lessons.json`, `activities.json` и папки `remarks`, `samples`, `guides`, `assignments`, `transcripts`;
- подготовка и проверка работы (`ClaudeAgent.RunAsync`, профиль `Draft`): ещё `items`, `analysis` и внутри папок работ `drafts/*/.previous`, `drafts/*/.failed`, `drafts/*/.owner`. Сама папка работы занятия с `.src` и `.check` открыта;
- разбор занятия и поиск заданий (`ClaudeAgent.RunLessonAsync`, профиль `Lesson`): пишут в `items` и `analysis`, но закрыта вся папка `drafts`. Для Word агент начинает файл с блока оформления между строками `---` (`font`, `size`, `spacing`, `margins`, `align`, `indent`, `numbers`), а `OfficeWriter` применяет его: шрифт, размер, интервал, поля, выравнивание, красную строку и нумерацию страниц. Строка `<center>…</center>` даёт титульный лист, `<pagebreak>` разрыв страницы.

`ClaudeAgent` живёт в этой библиотеке, чтобы им пользовались и приложение, и `Steward.Lms`. Отметка «Только анализ» забирает расшифровку и делает разбор, но задания не готовит. Ничего не сдаётся: файлы остаются у вас.

## Конвейер

У каждого задания есть шаг, который не хранится, а выводится из содержимого папок (`PipelineStepper`, `HomeworkStore.PipelineInfo`): «Найдено» (задание есть, работы нет), «Готово» (есть файл `Задание N…`; недописанные `.partial`, `.tmp`, `~$` не считаются), «Проверено» (есть отчёт проверки), «Сдано» (сдано в LMS, отмечено владельцем или `Done` в файле заданий). Хранятся только отметки владельца. Занятия в списке идут по шагу, полностью сданные в конце и приглушены.

**Нужно подтвердить.** Это не шаг, а остановка на «Найдено»: автоподготовка не берёт такое задание, пока владелец не подтвердит его или не исправит условие. `ItemAssessor` задаёт вопрос, если: уверенность `low`; нет расшифровки; нет условия задания из LMS (`assignments/<id>/assignment.md`); цитата `evidence` не найдена в расшифровке. Уверенность `medium` не останавливает, а показывает сомнение `doubt`. Задание без новых полей считается надёжным.

**Поля задания.** `evidence` цитата из расшифровки до 300 знаков (проверяется `EvidenceCheck` без учёта регистра, кавычек и лишних пробелов), `confidence` (`high`, `medium`, `low`; неизвестное значение считается пустым), `doubt` текст сомнения. Все три необязательные.

**Автоподготовка.** `HomeworkPreparer.RunAsync` идёт по занятиям от свежих к старым и готовит работу по одному заданию. Пропускает сданные (любым из трёх признаков), архивные, задания с готовым файлом, занятия без `PreparesHomework` и предметы с форматом «Не готовить», а также задания с вопросом. За запуск не больше `MaxPreparePerRun` работ (по умолчанию 2), весь шаг ограничен `PrepareBudgetMinutes` (по умолчанию 20): по истечении агент останавливается, готовое сохраняется. Неудача засчитывается в `prepare-attempts.json`, после трёх подряд задание ждёт владельца; успех сбрасывает счётчик. После новой работы сразу идёт проверка (`DraftCheckPrompt`); она не тратит лимит и попытки. Файлы задания, появившиеся за неудачную или прерванную попытку, переносятся в `drafts/<занятие>/.failed` (с новым именем при совпадении, ничего не затирается) и готовой работой не считаются; недописанные `.partial` и `.tmp` удаляются. Сами готовятся только занятия не старше `PrepareMaxAgeDays` дней (по умолчанию 21, граница включается, 0 значит без ограничения); у более старых только регистрируются образцы сданных работ, а работу можно подготовить кнопкой. Если не читаются список занятий или снимок работ LMS, запуск возвращает отчёт с ошибкой и не роняет фоновую задачу. Каждая готовая работа попадает в сводку строкой «Готова работа: предмет, задание».

**Образцы.** Когда задание сдано и у него есть файл работы, он копируется в `samples/<предмет>/` и записывается в `guides.json` образцом (`Id = sample:<занятие>:<номер>`, `Added`). В просьбу идут образцы своего предмета: два последних автоматических и все ручные (`Manual`). Повторная регистрация того же файла дату не меняет, выключенный образец остаётся выключенным.

**Замечания.** «Переделать» записывает замечание (вид: общее, условие, оформление, содержание, стиль; номер задания 0 значит всё занятие; галочка «Для всех предметов»). В просьбу идёт до 10 замечаний, общие и предметные поровну, свежие первыми. Замечания читаются как данные, не как инструкции. Редактируются на вкладке «Замечания» окна «Методические указания».

**Своя готовая работа.** `HomeworkStore.AttachOwnWork` копирует файл владельца как `Задание N.<расширение>` и шаг становится «Готово» без агента. Предел 50 МБ, ссылки (symlink) и папки отвергаются, расширение только латинское до 10 знаков. Прежние файлы задания уходят в `.previous` (с новым именем при совпадении, ничего не затирается), копия идёт через `.partial`. Прикрепление берёт `prepare.lock` без ожидания: пока идёт фоновая подготовка, оно отказывает. Имя прикреплённого файла записывается в `drafts/<занятие>/.owner/attached.json` (атомарно; папка `.owner` агенту закрыта и в готовые файлы не попадает): по этой отметке переделка не трогает работу владельца. «Удалить» тоже берёт `prepare.lock` без ожидания и во время фоновой подготовки ничего не удаляет.

**Задачи в Singularity.** `HomeworkTaskCreator` заводит задачи `hw:<занятие>:<номер>` только по заданиям без вопроса, не сданным и не в архиве. `HomeworkWorkLinker` дописывает в заметку заведённой задачи ссылку на готовый файл. Запись идёт только при `CreateTasks: true` в настройках `Steward.Lms`; Steward сам этот флаг не включает и не предлагает, включает его только владелец. При `false` в журнал пишется только «Завёл бы…» и «Добавил бы ссылку…».

## Сроки, проверка и переделка

- **Сроки.** `DeadlineBuilder` собирает несданные работы из LMS и найденные в расшифровках задания со сроком в ближайшую неделю (и просроченные не больше чем на неделю), без повторов. На экране «Статус» они показываются карточкой «Ближайшие сроки».
- **Кнопки задания.** «Открыть в LMS» (по полю `activity` задания или ссылке), «Отметить сданным» (отметка `submitted` в `item-states.json`, её можно снять), «Скопировать условие» (название, срок, требования и текст из LMS).
- **Правки условия.** `Steward.Lms` раз в 6 часов перечитывает страницу задания и сравнивает отпечаток (`fingerprint.txt`); при отличии обновляет `assignment.md`, пишет `changed.txt`, и на карточке задания две недели стоит пометка.
- **Проверка работы.** `DraftCheckPrompt` просит агента сверить готовую работу с условием и методичкой и найти факты без опоры; работа не меняется, отчёт лежит в `drafts/<занятие>/.check/report.md`.
- **Переделка.** В окно «Переделать» можно приложить файлы с замечаниями преподавателя: они копируются в `.remarks` (Word и презентации рядом с текстовой копией) и передаются агенту как данные. В `.previous` уходят только работы переделываемых заданий: работы сданных (любым признаком) и архивных заданий остаются на месте и остаются образцами, прикреплённые владельцем работы (по отметке `.owner/attached.json`) тоже не трогаются.
- **Файлы владельца при сбое.** Перед изменением `guides.json`, `item-states.json`, `item-confirmed.json`, `item-overrides.json`, `created.json`, `prepare-attempts.json` и `sample-registered.json` файл читается с повторами: если он так и не читается, запись не выполняется и выбрасывается `IOException` (фоновые шаги пишут это в журнал и пропускают задание), а испорченный JSON откладывается в `<имя>.bad` и пишется новый. Чтение только для показа по-прежнему даёт пустой список.
- **Конспект к практике.** Кнопка в читалке расшифровки копирует темы, формулировки, решения и задачи занятия одним текстом (`PracticeBrief`).

## Настройки предмета

В `data/homework/subject-options.json` у каждого предмета две настройки (в окне: вкладка «Домашние задания» выбранного предмета):

- **Готовить задания автоматически.** По умолчанию выключено. Фоновый процесс готовит работы только у предметов с включённым тумблером; кнопка «Подготовить задание» работает всегда. Общий предохранитель остаётся: `MaxPreparePerRun` в `lmssettings.json` (0 останавливает автоподготовку у всех предметов).
- **Откуда задания.** «Определять самому» (LMS, если у предмета там написано условие в несданной работе, иначе занятие), «В LMS» или «На занятии». У предмета с заданиями в LMS агент в расшифровках заданий не ищет и токены не тратит: карточки строятся по несданным работам LMS (`HomeworkStore.SyncLmsItems`) и дописываются в файл заданий самого свежего занятия предмета с расшифровкой. Номера уже стоящих там заданий не сдвигаются.
