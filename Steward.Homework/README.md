# Steward.Homework

Домашние задания по занятиям MTS Link: что нашли в расшифровке, в каком формате готовить и какие задачи завести в SingularityApp.

## Папка `data/homework`

| Путь | Кто пишет | Что внутри |
|---|---|---|
| `lessons.json` | выгрузка из MTS Link (позже) | `[{"id": "db-1022", "title": "…", "date": "2026-10-22"}]` |
| `transcripts/<id>.txt` | выгрузка из MTS Link (позже) | расшифровка занятия |
| `items/<id>.json` | агент (Claude) по просьбе из `HomeworkExtractionPrompt` | `[{"title", "due", "requirements", "link"}]` |
| `analysis/<id>.json` | агент (Claude) по просьбе из `LessonAnalysisPrompt` | подробный разбор занятия: тема, что было, пройденное, темы, формулировки, решения, задачи. Полный текст по ролям сюда не попадает |
| `drafts/<id>/Задание N. …` | `DraftBuilder` | готовые работы: `.docx`, `.pptx`, `.md` или файл с кодом. Агент пишет Markdown, `OfficeWriter` собирает из него Word и презентацию |
| `guides/guides.json`, `guides/Общие/…` | вкладка «Домашние задания» | методические указания и образцы работ, общие для всех предметов: файлы копируются сюда, пути к файлам и папкам и ссылки запоминаются, ссылки Google Диска и Документов скачиваются; Word и презентации читаются через текстовую копию в `guides/.text` вместе с оформлением (шрифт, размер, интервал, поля) |
| `created.json` | выгрузка | ключи задач и заметок, уже записанных в SingularityApp (`hw:`, `note:`, `draft:`) |
| `formats.json` | вкладка «Домашние задания» в приложении | формат по ключу занятия, по умолчанию Word |

## Поток

1. Выгрузка кладёт занятие и расшифровку (пока вручную).
2. Кнопка «Подготовить задания» в окне «Форматы ДЗ» запускает Claude в фоне одним заходом (`ClaudeAgent`: модель sonnet, только чтение и запись файлов, без сохранения сессии, чат не создаётся). Он читает расшифровку и пишет `items/<id>.json`, в окне идёт вращающаяся сфера, потом галочка или ошибка. Просьбу собирает `HomeworkExtractionPrompt`: текст расшифровки в неё не попадает, только путь, и помечен как данные, а не инструкции.
3. Программа [`Steward.Homework.Tasks`](../Steward.Homework.Tasks) создаёт задачи с ключом `hw:<занятие>:<номер>`: повторный запуск дублей не делает. Занятия с форматом «Не готовить» пропускаются.

4. После заданий `DraftBuilder` просит Claude выполнить каждое в выбранном формате и кладёт файлы в `drafts/<id>`; готовые не переделываются. `Steward.Lms` позже записывает разбор занятия в заметку SingularityApp (она обновляет заметку с резюме) и ссылку на готовый файл в задачу `hw:`. API SingularityApp (v2) не принимает вложения, поэтому в задаче лежит ссылка `file:///…` на файл на диске.

Какие материалы попадут в просьбу, решают галочки в окне «Методические указания» (`Enabled`) и отметки в окне «Подготовить задание»; дополнительное указание из того же окна добавляется в конец просьбы. Просьба на подготовку задания перечисляет методические указания (их требования обязательны) и образцы автора (ориентир по стилю и структуре, содержание не копируется), а папки с материалами по ссылкам на диск передаются агенту как `--add-dir`. Эти папки и файлы состояния Steward (`lesson-states.json`, `item-states.json`, `created.json`) агенту закрыты для записи правилами `--disallowedTools Edit(…)`, читать их можно. Для Word агент начинает файл с блока оформления между строками `---` (`font`, `size`, `spacing`, `margins`, `align`, `indent`, `numbers`), а `OfficeWriter` применяет его: шрифт, размер, интервал, поля, выравнивание, красную строку и нумерацию страниц. Строка `<center>…</center>` даёт титульный лист, `<pagebreak>` разрыв страницы.

`ClaudeAgent` живёт в этой библиотеке, чтобы им пользовались и приложение, и `Steward.Lms`. Отметка «Только анализ» забирает расшифровку и делает разбор, но задания не готовит. Ничего не сдаётся: файлы остаются у вас.

## Сроки, проверка и переделка

- **Сроки.** `DeadlineBuilder` собирает несданные работы из LMS и найденные в расшифровках задания со сроком в ближайшую неделю (и просроченные не больше чем на неделю), без повторов. На экране «Статус» они показываются карточкой «Ближайшие сроки».
- **Кнопки задания.** «Открыть в LMS» (по полю `activity` задания или ссылке), «Отметить сданным» (отметка `submitted` в `item-states.json`, её можно снять), «Скопировать условие» (название, срок, требования и текст из LMS).
- **Правки условия.** `Steward.Lms` раз в 6 часов перечитывает страницу задания и сравнивает отпечаток (`fingerprint.txt`); при отличии обновляет `assignment.md`, пишет `changed.txt`, и на карточке задания две недели стоит пометка.
- **Проверка работы.** `DraftCheckPrompt` просит агента сверить готовую работу с условием и методичкой и найти факты без опоры; работа не меняется, отчёт лежит в `drafts/<занятие>/.check/report.md`.
- **Переделка.** В окно «Переделать» можно приложить файлы с замечаниями преподавателя: они копируются в `.remarks` (Word и презентации рядом с текстовой копией) и передаются агенту как данные.
- **Конспект к практике.** Кнопка в читалке расшифровки копирует темы, формулировки, решения и задачи занятия одним текстом (`PracticeBrief`).
