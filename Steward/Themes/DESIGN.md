# Дизайн-система Steward

Тёмная тема «slate»: нейтральные сине-серые поверхности, синий акцент, зелёный, жёлтый и красный для состояний задач. Все значения лежат в `Steward/Themes`, остальной код берёт их по имени.

Посмотреть всё сразу: `Steward.exe --snapshot design.png design`.

## Файлы

| Файл | Что в нём |
|---|---|
| `Colors.xaml` | Единственное место с шестнадцатеричными цветами: `*Color` и `*Brush` |
| `Typography.xaml` | Шрифты, пять размеров текста и стили `Text*` |
| `Metrics.xaml` | Скругления, шаг отступов, готовые отступы |
| `Controls.xaml` | Стили кнопок, полей, карточек, плашек состояния, полосы прокрутки |

`App.xaml` подключает только `Themes/Controls.xaml`, он тянет остальные словари.

## Цвета

| Токен | Значение | Для чего |
|---|---|---|
| `Window` | `#0F172A` | Фон окна |
| `Surface` | `#1B2336` | Карточки, поля, плашки |
| `Raised` | `#273449` | Наведение, приподнятые элементы |
| `Line` | `#334155` | Разделители. Не несёт смысла, контраст не нужен |
| `LineStrong` | `#64748B` | Рамки полей, контраст не ниже 3:1 |
| `Text` | `#F8FAFC` | Основной текст |
| `Muted` | `#A9B6C9` | Подписи и вторичный текст |
| `Accent` | `#2563EB` | Заливка главной кнопки, текст на ней `OnAccent` |
| `AccentHover`, `AccentPressed` | `#1D4ED8`, `#1E40AF` | Состояния главной кнопки |
| `AccentText` | `#60A5FA` | Акцент как текст, рамка фокуса и выбранный элемент на тёмном фоне |
| `Ok`, `OkSurface` | `#22C55E`, `#12301F` | Работает |
| `Attention`, `AttentionSurface` | `#FBBF24`, `#3A2F12` | Ждёт решения |
| `Danger`, `DangerSurface` | `#F87171`, `#3B1D24` | Сбой, ошибка в поле |
| `Idle` | `#94A3B8` | Выключено или не запущено |
| `Working` | `#60A5FA` | Выполняется прямо сейчас |

Правила:
- Цвет задаётся только по имени: `{StaticResource SurfaceBrush}`. В WinForms-меню трея цвета берёт `TrayPalette` из тех же ресурсов.
- Акцент и «Ok» разведены: акцент синий, «работает» зелёный.
- Цвет никогда не единственный признак. У состояния есть слово («Работает», «Сбой»), у ошибки поля есть подпись, у плашки рамка цвета состояния, у точки кольцо, у выбранной вкладки рамка AccentText.
- Контраст проверяют тесты `DesignTokensTests`: текст не ниже 4.5:1, рамки и значки не ниже 3:1.

## Текст

Шрифт `Segoe UI` (`FontBase`), для идентификаторов и кодов `Cascadia Mono, Consolas` (`FontMono`).

| Размер | Токен | Стиль | Где |
|---|---|---|---|
| 12 | `FontSizeCaption` | `TextCaption`, `TextMono` | Подписи, время, подсказки |
| 14 | `FontSizeBody` | `TextBody`, `TextSecondary` | Основной текст, подробности, кнопки |
| 16 | `FontSizeBodyLarge` | `TextBodyLarge` | Название задачи |
| 18 | `FontSizeTitle` | `TextTitle` | Заголовок карточки |
| 24 | `FontSizeHeadline` | `TextHeadline` | Заголовок страницы |

Числом размер не пишется: `FontSize="{StaticResource FontSizeBody}"`.

## Форма и отступы

| Токен | Значение | Где |
|---|---|---|
| `RadiusField` | 8 | Поля, кнопки |
| `RadiusBadge` | 12 | Плашки, пункты меню |
| `RadiusCard` | 16 | Карточки |
| `RadiusWindow` | 22 | Окно |
| `RadiusSmall` | 4 | Полоса прокрутки |
| `RadiusFocus` | 10 | Кольцо фокуса вокруг кнопки |

Отступы идут с шагом 4: 4, 8, 12, 16, 24 (`Space1` .. `Space5`). Готовые: `PadCard`, `PadControl`, `PadField`, `GapCard`. Числа меньше 4 допустимы только для подгонки, например линии текста.

## Компоненты

| Стиль | Когда |
|---|---|
| `PrimaryButton` | Главное действие. На экране одна такая кнопка |
| `ActionButton` | Обычное действие на поверхности |
| `GhostButton` | Второстепенное действие без фона |
| `Field`, `SecretField`, `FieldInvalid` | Поле ввода, поле пароля, поле с ошибкой. Ошибку подписывает `HintError` |
| `Card` | Карточка задачи или записи журнала |
| `ToneBadge`, `ToneBadgeText`, `ToneDot` | Плашка с рамкой и точка с кольцом. Читают `Tone` из `DataContext`. Точка это `Control`, её размер задаёт вызывающий |
| `NavButton` | Пункт левого меню |
| `WindowChrome` | Рамка окна: градиент, скругление, тень |

Состояния у кнопок и полей:
- наведение: фон `Raised` у кнопок, рамка `Muted` у полей;
- нажатие: фон `Line` у обычных кнопок, `AccentPressed` у главной;
- выключено: прозрачность 0.5 и обычный курсор;
- фокус с клавиатуры: у кнопок кольцо `AccentText` 2 пикселя, у полей рамка `AccentText`.

## Чёткость текста

- Теней и других эффектов (DropShadowEffect, BlurEffect) на элементах с текстом нет: WPF рисует такой текст через промежуточное изображение, и он теряет чёткость. Глубину даёт рамка Line.
- Полупрозрачность (Opacity) на контейнерах с текстом не используется, приглушение делается цветом Muted.
- Манифест pp.manifest включает PerMonitorV2: окна рисуются в родном разрешении монитора, на 4К это важно.
- В окнах включены UseLayoutRounding и SnapsToDevicePixels, края и текст попадают на пиксели экрана.

## Добавляя новое

1. Нужен новый цвет: сначала `Colors.xaml` (цвет и кисть), потом использование. Подумай, нет ли подходящего.
2. Нужен новый стиль, который повторяется дважды, идёт в `Controls.xaml`, а не в окно.
3. Новый экран проверь снимком: `Steward.exe --snapshot экран.png main:страница`.
