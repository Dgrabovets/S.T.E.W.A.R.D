# Steward

Приложение в трее Windows. Запускает задачи из [`config/jobs.json`](../config/jobs.json) и показывает статус каждой. Как задачи запускаются и в каком формате пишут статус, описано в [`Steward.Status`](../Steward.Status/README.md).

## Что показывает

Иконка зелёная, если всё работает, и красная, если сбой у любой включённой задачи, о чём приходит уведомление. Щелчок по иконке открывает быстрый статус, двойной щелчок или пункт «Открыть приложение» главное окно с разделами:

- **Статус:** все задачи с цветом, подробностями и кнопкой «Запустить».
- **Идеи** и **ДЗ:** пока пустые, в них появятся результаты будущих процессов (рилсы, MTS Link) с кнопками решения.
- **Журнал:** что запускалось и чем закончилось.

Расписание пар из Docker показывается отдельной строкой. Для него приложение читает журнал контейнера: зелёная иконка значит, что синхронизация работает, подсказка показывает время последнего прогона, а при падении прогона приходит уведомление с текстом ошибки. Когда в таблице занятие убрали или перенесли, а также когда изменилась уже созданная пара, приходит уведомление «Расписание изменилось». Добавление новых пар уведомления не вызывает. Момент последнего показанного уведомления хранится в `data/last-notified.txt`, поэтому после перезапуска старое не повторяется.

Раздел настроек быстрого статуса редактирует `.env` расписания (интервал, проект, колонка, таблица, токен) и перезапускает контейнер.

## Запуск и сборка

Обычно приложение запускает `start-steward.ps1` при входе в Windows. Вручную:

```bash
dotnet run --project Steward/Steward.csproj
```

Второй экземпляр не запускается: он сразу завершается.

## Проверка вида окон

Окна можно нарисовать в PNG на выдуманных данных, не открывая их на рабочем столе:

```bash
Steward.exe --snapshot файл.png [popup | main[:status|ideas|homework|journal]]
```

## Устройство

| Папка | Что внутри |
|---|---|
| `Shell/` | Иконка в трее, меню, рисование окон в PNG |
| `Hosting/` | Хост задач: реестр, раннер, планировщик |
| `Monitoring/` | Опрос Docker, разбор журнала, уведомления об изменениях |
| `Models/`, `ViewModels/`, `Views/` | Данные, модели представления и окна |
| `Mvvm/`, `Controls/`, `Behaviors/` | Общие заготовки интерфейса |
