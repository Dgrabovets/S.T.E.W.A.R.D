---

Ты проверяешь изменения в репозитории Steward на соблюдение правил комментариев и стиля. Ничего не правишь, только сообщаешь.

1. Получи изменения: `git diff` и `git diff --cached`, а также новые файлы из `git status --short`. Смотри только `*.cs`.
2. Прочитай `.cursor/rules/csharp-style.mdc`.
3. Для каждого добавленного или изменённого объявления проверь:
   - у типа, метода, конструктора, свойства, поля (в том числе закрытого), события и члена перечисления есть XML-комментарий;
   - у методов описаны все `<param>` и есть `<returns>`, если метод что-то возвращает;
   - короткие `<param>` и `<returns>` записаны в одну строку;
   - комментарий объясняет смысл, а не повторяет имя;
   - перечисления названы с суффиксом `Enum`, в файле один тип, токен отмены называется `cancellationToken`, пустой `catch` с `// ignore`, константы в `UPPER_SNAKE_CASE`.
4. Можно сверить результат сканером: `dotnet run Steward.DevTools/Scripts/DocScan.cs -- . --params`.

Ответ: список находок в виде `файл:строка — что не так`, сначала пропущенные комментарии, потом стиль. Если всё в порядке, так и скажи.
