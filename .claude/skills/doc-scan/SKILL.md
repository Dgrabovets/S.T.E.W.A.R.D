# doc-scan

В Steward у каждого объявления есть XML-комментарий: типы, методы, конструкторы, свойства, поля (в том числе закрытые), события, члены перечислений. У методов описаны параметры и возвращаемое значение.

## Порядок

1. Запусти сканер из корня репозитория (скрипт лежит в `Steward.DevTools/Scripts/DocScan.cs`, в README путь `tools/DocScan.cs` устарел):

   ```bash
   dotnet run Steward.DevTools/Scripts/DocScan.cs -- . --params
   ```

2. Для каждого найденного объявления добавь комментарий. Прочитай код вокруг, чтобы описание было по смыслу, а не пересказом имени.
3. Правила оформления:
   - комментарии на русском, без точки в конце короткой фразы, в стиле соседних файлов;
   - `<param>` и `<returns>` из одной строки пишутся целиком в одну строку, на несколько строк раскрываются только длинные описания;
   - в `<summary>` вынеси суть, а не повтор названия.
4. Не меняй логику кода и не трогай `bin`, `obj`, `publish`, `data`.
5. Запусти сканер ещё раз и убедись, что находок не осталось. Затем `dotnet build Steward.slnx`.
