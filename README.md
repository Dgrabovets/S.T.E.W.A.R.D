# SingularityTools

Личные утилиты, которые заводят задачи в SingularityApp, и приложение в трее Windows, которое запускает их и показывает статус каждой.

| Папка | Что это |
|---|---|
| [`UltimateParser/`](UltimateParser/README.md) | Переносит расписание из Google Таблицы в задачи. Работает в Docker. Здесь же приложение в трее (`UltimateParser.Tray`) |
| [`MailToSingularity/`](MailToSingularity/README.md) | Проверяет учебную почту и ставит задачи на письма, которые требуют ответа или содержат отзыв |
| [`Status/`](Status/README.md) | Общий формат статуса процессов, реестр задач и раннер, который их запускает |
| [`Whisper/`](Whisper/README.md) | Локальная расшифровка речи из видео, пока для рилсов |
| [`config/jobs.json`](config/jobs.json) | Список задач, которые приложение запускает само |

Всё собирается на .NET 10 одним решением `SingularityTools.slnx` (Whisper написан на Python).

## Как это устроено

```
config/jobs.json ──► приложение в трее ──запускает──► процессы (почта, ...)
                              ▲                              │
                              └──── читает data/status/*.json ◄── каждый пишет свой статус
```

- **Расписание пар** работает отдельно, в Docker, а приложение читает его журнал.
- **Остальные задачи** запускает приложение: при старте, каждый день в заданное время или по интервалу, а ещё по кнопке «Запустить». Это заменяет задачи Планировщика Windows.
- **Статус** каждой задачи лежит в одном формате. Новой задаче достаточно записать файл статуса и добавить строку в `config/jobs.json`, менять приложение не нужно.

## Приложение в трее

Иконка зелёная, если всё работает, и красная, если сбой у любой включённой задачи, о чём приходит уведомление. Щелчок открывает быстрый статус, двойной щелчок или пункт «Открыть приложение» главное окно:

- **Статус:** все задачи с цветом, подробностями и кнопкой «Запустить».
- **Идеи** и **ДЗ:** пока пустые, в них появятся результаты будущих процессов (рилсы, MTS Link) с кнопками решения.
- **Журнал:** что запускалось и чем закончилось.

Задача «Почта» в `config/jobs.json` по умолчанию выключена: сначала нужно настроить [`MailToSingularity`](MailToSingularity/README.md).

## Сборка и проверка

```bash
dotnet build SingularityTools.slnx
dotnet test SingularityTools.slnx
```

Нужен .NET 10 SDK. Проект трея собирается только под Windows, поэтому в Docker участвует лишь `UltimateParser/`.

## Комментарии

В коде принято описывать XML-комментарием каждое объявление, включая закрытые поля и методы, а у методов ещё параметры и возвращаемое значение. Проверка находит всё, где комментария нет:

```bash
dotnet run tools/DocScan.cs -- . --params
```

Ключ `--params` добавляет проверку параметров и `<returns>`. Результат «0 из N объявлений» значит, что пробелов нет.

## Диск

Всё, что пишет репозиторий, остаётся на диске, где он лежит: `data/` (статусы, журнал запусков, временные файлы), `Whisper/.venv` и модель в `Whisper/models`. Временная папка запущенных задач тоже указывает в `data/tmp`.

## Секреты

Ни токены, ни пароли в репозиторий не попадают: `UltimateParser/.env` и `MailToSingularity/appsettings.json` лежат в `.gitignore`. Образцы без значений: `UltimateParser/.env.example` и `MailToSingularity/appsettings.example.json`.
