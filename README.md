# UltimateParser

Переносит расписание из Google Sheets в Singularity. Сейчас читается колонка `РКИ-2-26`: каждая пара становится задачей с датой, временем и длительностью. Время в таблице — московское. Повторный запуск обновляет уже созданные задачи и архивирует те, чья ячейка опустела. Задачи, отмеченные выполненными, не меняются. Прошедшая пара текущей недели создаётся и сразу отмечается выполненной. Пара более ранней недели не создаётся.

Таблица должна быть доступна по ссылке. Сервис скачивает CSV без аккаунта Google. Если доступ закроют, синхронизация остановится, пока ссылку снова не откроют.

## Токен Singularity

В личном кабинете Singularity создайте токен с доступом к сущностям «Проект» и «Задача» на чтение и запись. Скопируйте `.env.example` в `.env` и вставьте токен в `SINGULARITY_TOKEN`. Файл `.env` не коммитится.

Задачи попадают в проект с названием из `PROJECT_TITLE` (по умолчанию `Расписание`). Если такого проекта нет, сервис его создаёт. Занятие из объединённой ячейки попадает в каждую группу этого диапазона.

## Запуск

Постоянно, сразу один прогон и дальше каждые `SYNC_INTERVAL_MINUTES` минут (по умолчанию 30):

```bash
docker compose up -d
```

Один прогон:

```bash
docker compose run --rm sync --once
```

Логи: `docker compose logs -f sync`.

При входе в Windows задача планировщика `UltimateParser Sync` запускает `start-sync.ps1`: скрипт дожидается Docker и поднимает контейнер. У контейнера стоит `restart: unless-stopped`, поэтому дальше его поднимает сам Docker.

Тесты разбора сетки и сверки:

```bash
dotnet test
```
